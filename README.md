# School Health Check App

小学1年生が学校の内科健診について事前に学べる、Streamlit製のWebアプリです。

## 制作背景

学校の集中講義のワークショップで制作しました。同じ班にいた元保健室の先生から、学校健診では限られた時間で多くの児童を診るため、児童一人ひとりに検査の目的や方法を十分に説明することが難しいという意見を聞いたことが開発のきっかけです。

児童が「なぜ聴診器を肌に直接当てることがあるのか」を事前に理解し、健診に対する不安や羞恥心を軽減することを目的としています。

## 主な機能

- 画面上の聴診器をドラッグして胸へ動かす操作
- 服の上から聴診した場合の、衣服の擦れる音を含む心拍音
- 必要な範囲だけ服を動かし、肌へ直接当てた場合の聞き取りやすい心拍音
- 2種類の音を比較した学習
- カーテン、ついたて、タオルなどのプライバシーへの配慮の説明

## 工夫した点

- 小学1年生向けに、漢字をできるだけ使わず、ひらがな中心で表示
- 文章を短くし、大きな文字やボタン、イラストを使用
- 説明を読むだけでなく、聴診器を動かして音を聞く体験型の構成
- 「服の上では聞こえない」と断定せず、衣服の種類や動きによって雑音が入り、確認しにくくなることがあると表現
- 身体を見えにくくする配慮や、嫌なときは気持ちを伝えてよいことも説明

## 使用技術

- Python
- Streamlit
- HTML / CSS / JavaScript
- Web Audio API

## 実行方法

### 1. ファイルをダウンロード

このリポジトリをダウンロードし、フォルダへ移動します。

```bash
cd school-health-check-app
```

### 2. 必要なライブラリをインストール

```bash
python -m pip install -r requirements.txt
```

### 3. アプリを起動

```bash
python -m streamlit run app.py
```

`app.py`をPythonで直接実行して起動することもできます。

```bash
python app.py
```

起動後、通常はWebブラウザでアプリが開きます。
